## Ключевые решения

- **Идентификация:** гибрид regex + словари + контекстные правила (паттерн Analyzer/Recognizer, по образцу Microsoft Presidio).
- **Хранилище:** Redis (внешний), клиент Lettuce.
- **Формат маски:** токенизация с сохранением длины (`45** ****56`).
- **Производительность:** виртуальные потоки (Spring Boot 3.5 / Java 21).
- **Отказоустойчивость:** circuit breaker (Resilience4j), rate limiting (Bucket4j).
- **Качество:** checksum-валидация (ИНН, Luhn), контекстные правила, стратегия «лучше перемаскировать».
