# Модуль безопасности персональных данных

Высоконагруженный прокси-сервис для маскирования/демаскирования персональных данных (ПД) перед обращением к LLM. Реализует контракт `POST /process` из ТЗ.

## Возможности

- **Идентификация ПД**: ФИО, даты (рождения и выдачи), паспорт (в т.ч. «серия … номер …»), гражданство, орган выдачи, код подразделения, в/у, адрес (страна, индекс, город, улица, дом, квартира), email, телефон, ИНН, номер карты, CVV, ПИН, имя держателя.
- **Маскирование**: замена ПД на `*` с сохранением длины и краёв; поддержка регистра, разных форматов дат, дат текстом, разделяющих слов.
- **Токенизация**: замена ПД на плейсхолдеры `{TYPE_N}` (например, `{FIO_1}`) — детерминированно и легко детокенизировать.
- **Демаскирование/детокенизация**: восстановление исходного текста по `payload_id` с сохранением позиций.
- **Безопасность**: проверка систем (`X-System-Id`), маскирование ПД в логах, rate-limiting (429 + Retry-After).
- **Гибкая настройка**: список систем, перечень типов ПД, вид маскирования (звёздочки/токены) и разрешение демаскирования — по каждой системе.
- **Метрики**: latency, RPS, TPS (Prometheus-формат на `/metrics`).
- **Производительность**: ~100µs на запрос, RPS 4000+ на одном ядре, обработка до 100k токенов.

## Быстрый старт

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

Или через Docker: `docker build -t pii-module . && docker run -p 8000:8000 pii-module`.

## Контракт API

```bash
# Маскирование (первый запрос с новым payload_id)
curl -X POST http://localhost:8000/process \
  -H "Content-Type: application/json" -H "X-System-Id: test" \
  -d '{"payload": "Клиент Иванов Иван Иванович, паспорт 4509 123456", "payload_id": "abc123"}'
# → {"result": "Клиент И*******************, паспорт 45*******56"}

# Демаскирование (второй запрос с тем же payload_id)
curl -X POST http://localhost:8000/process \
  -H "Content-Type: application/json" -H "X-System-Id: test" \
  -d '{"payload": "Клиент И*******************, паспорт 45*******56", "payload_id": "abc123"}'
# → {"result": "Клиент Иванов Иван Иванович, паспорт 4509 123456"}
```

## Настройка

Скопируйте `.env.example` в `.env`. Ключевые параметры:

- `ALLOWED_SYSTEMS` — список систем, которым разрешено обращаться (через заголовок `X-System-Id`).
- `SYSTEM_POLICIES` — JSON: какие типы ПД маскировать, вид маскирования (`mask`/`token`) и разрешено ли демаскирование для каждой системы.
- `RATE_LIMIT_RPS` — лимит запросов в секунду (429 при превышении).
- `WORKERS` — число воркеров uvicorn для масштабирования.

## Структура

```
app/
  main.py       # FastAPI приложение, POST /process
  detectors.py  # детекторы ПД (regex + словари)
  masking.py    # маскирование/демаскирование
  store.py      # in-memory хранилище соответствий
  security.py   # проверка систем, защита логов
  ratelimit.py  # rate-limiting (429 + Retry-After)
  metrics.py    # метрики latency/RPS/TPS
  config.py     # конфигурация
  pii_types.py  # типы ПД
tests/          # тесты
```
