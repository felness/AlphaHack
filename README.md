# AlphaHack — Модуль безопасности персональных данных

Прокси-сервис между системой-потребителем и LLM: идентификация, маскирование и демаскирование персональных данных.

## Технологии

- **Kotlin** 2.4.20
- **Spring Boot** 4.1.1 (Spring Framework 7.0)
- **Java** 21+
- **Redis** (Lettuce)
- **Micrometer / Prometheus**

## Ключевой API-контракт

```
POST /process
{ "payload": "<строка>", "payload_id": "<id>" } → { "result": "<строка>" }
```

- Первый запрос с новым `payload_id` — маскирование.
- Второй запрос с тем же `payload_id` — демаскирование.
